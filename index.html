📝 Question Format

Har question number se start hona chahiye.

Question text hamesha <Q> aur </Q> tags ke andar hona chahiye. Options <A> aur </A> mein hone chahiye.

Correct option ke aage asterisk (*) lagana zaroori hai.

1. <Q> Psychology is the scientific study of? </Q> <A> *(a) Behaviour and mental processes (b) Only behaviour (c) Only mind (d) Human biology </A>

🤖 AI Auto-Format (Recommended)

Apne notes ko format karne ke liye AI use karein:

  • Neeche diya gaya button dabakar prompt copy karein.
  • Ise GEMINI ya kisi bhi AI tool mein paste karein.
  • Apne questions/notes paste karein aur output copy karke yahan use karein.
